# 0004 — No legal-advice gate

- Status: proposed
- Date: 2026-11-20
- Decided by: ON8ST (proposal to the repository owner)
- Affects: project

## Context

Earlier documents made publishing conditional on legal or IP advice.

## Decision

There is no gate on legal or IP advice. Publishing follows only the explicit go of the repository owner (AGENTS.md rule 4).

## Consequences

Old conditions of this kind were removed from all components.
